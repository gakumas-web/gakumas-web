# 内置预览账号

通过右上角「账号 → 启用预览」安装内置演示库存，使用独立的浏览器账号档案。已导入账号保持原样，可从账号选择框切换回来。再次启用已有预览档案保留试用过程中修改的标签、收藏和库存，仅将 P 经验同步到当前公开等级表的满级门槛。刷新或重新进入预览账号时也会同步；应用更新的公开资料后，等级上限随表更新，不固定为某个等级。需要重新开始其他试用数据时，先清除当前预览账号数据，再次启用。

预览数据通过与目录导入相同的快照和培养阵容关联校验。文件位于 `resources/preview-account.json`，仅在启用时读取，不在启动页面时下载。首次安装同时生成预览专用标签，覆盖普通回忆、选拔回忆、多标签、未标记条目和空标签。

## 部署开关

通用部署默认关闭。关闭时隐藏预览入口和已保存的预览档案，不打包预览 JSON（包括压缩副本）；浏览器中的既有预览数据保留，重新开启后可以继续使用。

- 静态构建：`python -B tools/build.py --preview-account` 开启，`--no-preview-account` 关闭；省略参数默认关闭。
- Pages 构建脚本同样接受上述开关，默认关闭。
- Docker：`docker build --build-arg ENABLE_PREVIEW_ACCOUNT=true -t gakumas-web .` 开启，构建参数默认 `false`。
- Compose：`ENABLE_PREVIEW_ACCOUNT=true docker compose up --build -d` 开启，环境变量省略时默认关闭。
- 当前仓库用于测试站，Pages 手动发布表单的 `preview_account` 默认勾选；可取消勾选关闭。此测试站默认值不改变通用构建及 Docker 的默认关闭行为。

程序发布清单记录实际开关状态。切换选项需要重新构建站点；仅修改运行中容器的环境变量不会改变已生成的静态文件。

## 脱敏边界

用户明确选择保留真实来源模拟副本中的卡组组合、持有状态、等级、突破、附魔、库存数量及成就进度，并接受组合特征仍可能被关联。因此该样本是去除直接标识的演示数据，不宣称不可重识别。

- P 经验使用当前公开等级表满级所需的累计经验，属于合成演示值，不读取来源账号经验补齐。此自动同步仅作用于内置预览账号的经验字段，不改其他账号、标签、收藏、选拔库存或历史记录。
- 账号、普通回忆、选拔回忆及详情引用全部改为预览标识，引用关系保持一致，不发布原始标识映射。
- 采集、拍摄、获取、使用和过期时间重新生成，不保留原始时间间隔；零值及是否存在突破时间的状态保持。
- 未匹配公开配置的研究和培养关联标识重新映射。已匹配公开配置的游戏标签保留，不混入原账号的自定义标签或备注。
- 照片资源标识置空；通过快照字段白名单排除照片路径、高分记录标识、昵称、自由备注及认证字段。
- 服装、技能卡、道具和支援剧情等游戏配置引用用于保持原有展示和培养阵容关系。其组合与进度属于用户明确接受保留的特征。
- 预览自定义标签在首次安装时新建，独立于来源账号。标签是试用内容，不表示原账号的整理偏好。

## 维护与验证

`tools/build_preview_account.mjs` 只接受显式指定的本地模拟副本和公开配置目录。禁止对原始采集器目录运行旧提取脚本来自动更新预览。更新样本必须重新获得对应来源数据的授权，再核对直接标识、关系引用和保留范围。

生成器从指定公开目录的 `ProducerLevel` 表计算满级经验；缺表或上限矛盾时停止，不输出缺经验的预览。浏览器优先使用当前已验证内容的上限，资料暂不可用时保留预览文件中的有效经验。

生成后执行预览合同测试和实际浏览器入口验收，验证首次安装、重复启用、账号切换、标签保存、六页签以及无上传。公开候选检查仍按原规则执行；内置账号使用明确的 `synthetic-` 标识，不为此关闭扫描。
