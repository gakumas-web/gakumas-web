## 文档维护规则

- 项目入口保留必要的启动与使用说明，具体合同和操作流程归各主题文档。
- 程序版本、内容来源、引擎版本、工作流参数和工具链要求以对应配置文件为准，说明不另行维护一份“最新版本”列表。
- 账号导入、公开内容、图片缓存、算法基准分别说明；不要把合并、上传、发布和部署混写为同一个完成状态。
- 新增主题时更新本索引。纯文档修改只核对差异、链接和代码依据，不启动业务流程或重新发布。
